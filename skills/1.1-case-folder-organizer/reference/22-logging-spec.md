# 操作日志规范

操作日志保存为 `文件整理操作日志.txt`,存放于案件文件夹根目录。采用追加方式写入,不覆盖历史记录。

---

## 日志模板

```
文件整理操作日志
案件:[文件夹名]
执行时间:YYYY-MM-DD HH:MM:SS
触发方式:手动 / FSEvents / 定时轮询
本次处理文件数:N(增量)/ 全量
======================================================================

【新建目录】
  [新建目录] 1.起诉状和证据

【文件操作】
  [重命名] 原文件名 → 新文件名
  [移动]   文件名 → 目标目录/
  [删除]   文件名  原因:重复文件

【文件夹重命名】
  [文件夹] 原名 → 新名

【跳过】
  [跳过] 文件名  原因:目标已存在

【索引更新】
  [索引更新] .case_index.json 已更新,共 N 个文件

【待人工处理】
  1. 说明
  当前 Z.待归类/ 文件数:N
======================================================================
```

---

## 必填字段

- **执行时间**:精确到秒
- **触发方式**:手动 / FSEvents / 定时轮询,三选一
- **本次处理文件数**:增量模式下的变更文件数,全量模式下的总数
- **索引更新记录**:每次运行必记录
- **Z.待归类/ 文件数**:每次运行必记录当前数量,便于律师监控

---

## 日志生命周期

- 日志文件**追加**写入,永不覆盖
- 每次运行在上次记录后追加一段
- 用 `======` 分隔线区分运行记录
