# 证据自动合并与页码回填规则

**适用范围**:`1.起诉状和证据`、`3.答辩和证据`、`4.反诉和证据`(代理被告/反诉方时),规则和优先级完全一致。

---

## 触发判断

### Step 1:Python 自动判断

解析 `证据目录_姓名.docx`,提取表格中最后一个证据序号 N,检查对应目录内是否存在 `证据N XXX.pdf`:

```
IF  证据目录最后序号 = N
AND 证据N XXX.pdf 存在
THEN  判断证据已完整 → 触发弹窗确认
```

### Step 2:用户确认

弹窗提示:「系统发现您已完成证据制作,是否自动合并所有证据生成证据(合并).pdf?」用户确认后执行,取消则跳过并记录。

---

## 执行步骤

1. 按序号顺序合并 `证据1～N.pdf` → 生成 `证据(合并).pdf`
2. 计算每份证据的页数,推算合并文件中各证据的起始页码(证据 1 第 1 页 = 页码 1)
3. **页码回填**(肯定式判断,不确定则跳过):
   - Python 读取 `证据目录_姓名.docx` 表格
   - 检查第一行最后一列单元格,若包含"页码"、"页次"、"页"等关键词 → 确认为页码列,执行回填
   - 回填格式:`起始页-结束页`,例如 `1-3`、`15-49`
   - 无法肯定识别页码列 → 跳过,记录跳过原因,写入 `skill_handoff.page_fill_status = "skipped"`,预留接口供后续专项 skill 处理

---

## 快照字段更新

合并完成后写入 `.case_snapshot.json`:

```json
{
  "skill_handoff": {
    "evidence_merged_first": true,
    "evidence_count_first": N,
    "page_fill_status": "filled" | "skipped" | "pending",
    "page_fill_skip_reason": "..."
  }
}
```
