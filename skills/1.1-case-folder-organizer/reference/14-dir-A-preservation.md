# `A.财产保全` 归类规则

---

## 触发条件

识别到任何保全类文件,即建立。不区分诉前保全还是诉中保全。

---

## 完整内容清单

| 文件 | 命名格式 | 备注 |
|------|---------|------|
| 财产保全申请书 | `财产保全申请书_姓名.docx/.pdf` | 有 docx = 我方申请;仅 pdf = 对方申请 |
| 财产线索 | `财产线索_姓名.pdf` / `财产线索1_姓名.pdf` | 多份时加序号 |
| 担保合同 | `担保合同.pdf` | |
| 担保函 | `担保函.pdf` | |
| 担保材料 | `担保材料.pdf` | 担保合同与担保函合并为单一 PDF 时使用 |
| 保全费发票 | `保全费发票.pdf` | |
| 财产保全裁定书 | `财产保全裁定书.pdf` | |
| 听证通知书 | `听证通知书.pdf` | |
| 听证笔录 | `听证笔录.pdf` | |
| 复议申请书 | `复议申请书_姓名.docx/.pdf` | |

| 续期申请书 | `续期申请书_姓名.docx/.pdf` | |

---

## 关键规则

- 担保合同和担保函如为两个独立文件,各自独立命名;合并为单一 PDF 时命名为 `担保材料.pdf`,不拆分
- `0.委托发票/` 与 `A.财产保全/` 委托手续不重复放置:A 内仅放保全阶段单独出具的授权委托书和所函
- 保全转执行的衔接文件归入 `B.执行/`,不归入 `A.财产保全/`

---
