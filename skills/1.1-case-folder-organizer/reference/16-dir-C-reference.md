# `C.参考案例和法规` 归类规则

---

## 收录范围

类案判决书、法律法规、部门规章、政策文件、新闻报道(委托后)、学术文章、公众号文章、参考图片等非核心参考材料。

---

## 关键规则

- **不改名**:保留文件原始名称
- **不建子目录**:所有文件平铺存放
- **不做 OCR/LLM 分析**:直接归类移入,零 token 消耗
- **容忍杂乱**:文件名混乱、格式各异均可接受

---

## 与 `0.委托发票` 的区分

新闻报道按 mtime 判断(详见 `reference/04-dir-0-entrustment.md`):
- mtime ≤ 合同签署日期 → `0.委托发票`
- mtime > 合同签署日期 → `C.参考案例和法规`

---

## 与判决书归类树的交叉

若识别到判决书不属于本案(当事人姓名与委托人不匹配),按 `reference/19-judgment-detection.md` Step 3 归入此目录,不改名。
