# 收案前阶段降级分类规则

> **触发条件**:文件夹中无起诉状、上诉状、再审申请书、答辩状、反诉状、法院通知（含受理通知、应诉通知、举证通知、传票等）、管辖裁定、保全裁定等任何诉讼阶段文件,说明案件处于委托前/咨询阶段,尚未进入正式诉讼程序。

---

## 处理策略

不建立 1～9 号诉讼阶段文件夹。`0.委托发票/` 仅在识别到真实律师委托文件时才建立(法律服务合同/授权委托书/所函/律师费发票)。其余文件按以下语义类型目录直接平铺在**根目录**下归类:

| 识别到的文件类型 | 归入目录 | 说明 |
|----------------|---------|------|
| 法律服务合同、授权委托书、所函、律师费发票、身份证 | `0.委托发票/` | **有此类文件才建立 0 号文件夹** |
| 当事人之间的业务合同、协议、补充协议 | 根目录下新建 `合同文件/` | **不归入 0 号**,这是纠纷各方的业务合同,非律师委托文件 |
| 数据表格、账单、发票(非律师费)、消耗数据 | 根目录下新建 `账单数据/` | |
| 往来函件、回函、通知、催告 | 根目录下新建 `往来函件/` | |
| 聊天记录截图、沟通记录整理 | `Z.原始证据/` | |
| 音频、视频录音 | `Z.原始证据/` | |
| 律师内部分析文件、风险告知书、法律建议书 | `Z.待归类/` | 含"告知"/"建议书"/"法律意见"/"风险提示"等关键词的律师文书,无标准目录承接 |
| 判决书(参考用) | `C.参考案例和法规/` | |
| 其他无法识别 | `Z.待归类/` | |

**根目录语义子目录命名固定**:`合同文件/`、`账单数据/`、`往来函件/`,不得使用其他名称,确保多次运行结果一致。

## 进入诉讼阶段时的文件迁移

下次运行 skill 时,若首次识别到诉讼阶段文件(起诉状/上诉状/答辩状/反诉状/法院通知/管辖裁定/保全裁定等;授权委托书与法律服务合同属 0 号委托文件,不在此列),自动触发迁移逻辑:

1. 建立 `0.委托发票/`(如尚未建立)
2. 将根目录 `合同文件/`、`账单数据/`、`往来函件/` 中属于委托手续的文件移入 `0.委托发票/`
3. 业务合同从 `合同文件/` 移入 `1.起诉状和证据/`(作为证据材料)
4. 清空后删除已清空的根目录语义子目录
5. 更新 `case_stage` 为对应诉讼阶段

## 服务方案和报价联动

**触发条件**（满足任一，详见 `reference/04-dir-0-entrustment.md` 的"联动规则(服务方案和报价)"部分）：

- `0.委托发票/` 目录首次创建
- `0.委托发票/` 内新增文件名含"委托"/"服务合同"/"Legal Service Agreement"的文件

**触发动作**：

检查案件根目录下是否存在 `服务方案和报价_*.docx` 或 `服务方案和报价_*.pdf`，若存在则移入 `0.委托发票/`，写入操作日志。

**设计说明**：

- 服务方案和报价是收案前阶段的核心交付物，应在委托手续完成后及时归入 `0.委托发票/`
- 详细联动逻辑统一维护在 `04-dir-0-entrustment.md`，避免多处维护导致不一致
