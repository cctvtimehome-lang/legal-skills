# 法院文书兜底归类原则

当遇到规则中未明确列举的文件类型时(涉外诉讼文书、合并审理裁定、合议庭组成人员告知书、送达回证、谈话笔录等):

---

## 兜底识别树

```
Step 1:OCR 提取文本
Step 2:LLM 识别文书性质
  ├── 法院作出的文书
  │     ├── 案号含民初/一审相关 → 归入 2.法院通知 一审/,不改名
  │     └── 案号含民终/二审相关 → 归入 6.法院通知 二审/,不改名
  ├── 当事人/律师文书 → 按已有规则归类
  └── 无法判断 → 归入 Z.待归类/,记录日志
```

---

## 关键原则

- **不改名**:兜底归类的法院文书保留原始文件名
- **只归入已有目录**:严禁为兜底文件新建非标准目录
- **记录日志**:无法判断的文件必须在 `文件整理操作日志.txt` 中注明
