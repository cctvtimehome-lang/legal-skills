# 代理被告:合并 PDF 自动拆分与归类规则

---

## 触发条件

一级目录下出现体积较大的单一 PDF,且代理方向已判断为**被告**,则触发拆分流程。

---

## 拆分逻辑(宁可不拆,不可误拆)

pdfplumber 逐页提取文本,识别页面顶部或居中的文书标题关键词:

| 关键词 | 识别为 |
|--------|--------|
| 民事起诉状、起诉状 | 起诉状 |
| 证据目录 | 证据目录 |
| 证据\d+、附件\d+ | 证据 N |
| 传票 | 传票 |
| 应诉通知书 | 应诉通知 |
| 举证通知书 | 举证通知 |
| 诉讼权利义务告知书 | 权利义务告知书 |

```
IF  某段关键词明确匹配,置信度高
THEN  拆分该段,改名,归入对应目录

IF  某段无法肯定识别文书类型
THEN  保留该段整体,归入 Z.待归类/,标注"来源:合并PDF,页码X-Y,无法识别"
```

支持**部分拆分**:能识别的归位,无法识别的暂存,互不影响。

---

## 拆分后归类

| 识别结果 | 目标路径 | 命名规范 |
|---------|---------|---------|
| 起诉状 | `1.起诉状和证据/` | `起诉状_对方姓名.pdf` |
| 证据目录 | `1.起诉状和证据/` | `证据目录_对方姓名.pdf` |
| 证据 N | `1.起诉状和证据/` | `证据N XXX.pdf` |
| 传票 | 一级目录(临时) | `传票YYYYMMDD HHMM.pdf` |
| 应诉通知、举证通知、权利义务告知书 | `2.法院通知 一审/` | 保留文书类型名称 |
| 无法识别 | `Z.待归类/` | 保留原始页码范围标注 |

---

## 传票生命周期

```
IF  传票文件名中的日期时间 < 当前日期时间
THEN  静默自动移入对应法院通知目录,记录日志,无需用户二次确认
      一审传票 → 2.法院通知 一审/
      二审传票 → 6.法院通知 二审/
      再审传票 → 9.法院通知 再审/

IF  传票文件名中的日期时间 ≥ 当前日期时间
THEN  保留在一级目录,不做任何操作
```

传票日期解析依赖规范格式 `传票YYYYMMDD HHMM.pdf`,格式不符则标注 warning 待人工处理。
