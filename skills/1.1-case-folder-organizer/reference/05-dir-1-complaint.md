# `1.起诉状和证据` 归类规则

本目录**只存放**:起诉状、证据目录、证据 1～N、证据(合并)。不放其他任何文件。

---

## 命名规范

| 文件 | 命名格式 | 说明 |
|------|---------|------|
| 起诉状原件 | `起诉状_姓名.docx` | 律师起草的 Word 版 |
| 起诉状盖章版 | `起诉状_姓名.pdf` | 签字/盖章后扫描版 |
| 证据目录原件 | `证据目录_姓名.docx` | 律师起草的 Word 版 |
| 证据目录盖章版 | `证据目录_姓名.pdf` | 签字/盖章后扫描版 |
| 单份证据 | `证据N XXX.pdf` | N 为序号,XXX 为证据名称 |
| 合并证据 | `证据(合并).pdf` | 证据 1～N 合并后的完整版,自动生成 |

---

## 代理原告 vs 代理被告文件对照

| 文件 | 代理原告 | 代理被告 |
|------|---------|---------|
| 起诉状_姓名.docx | ✅ 律师自己起草 | ❌ 不存在 |
| 起诉状_姓名.pdf | ✅ 签字/盖章版 | ✅ 法院送达版 |
| 证据目录_姓名.docx | ✅ 律师自己起草 | ❌ 不存在 |
| 证据目录_姓名.pdf | 可有可无 | ✅ 法院送达版,必然存在 |
| 证据 1～N.pdf | ✅ | ✅ |
| 证据(合并).pdf | 完成后自动生成 | 完成后自动生成 |

---

## 代理被告的合并 PDF 拆分

代理被告时,法院通常送达合并 PDF(起诉状 + 证据目录 + 证据 1~N + 法院通知拼成一份大 PDF)。拆分规则见 `reference/08-pdf-split.md`。

## 证据自动合并

完成证据制作后自动生成 `证据(合并).pdf`,规则见 `reference/07-evidence-merge.md`。

---

## 劳动争议复用说明

劳动案件中,本目录规则对应 `4.起诉和证据`(仲裁前置后的诉讼阶段)。命名规范、代理原告/被告文件对照、合并 PDF 拆分、证据自动合并规则与本目录完全一致,仅阶段语境为"起诉"而非"仲裁申请"。
