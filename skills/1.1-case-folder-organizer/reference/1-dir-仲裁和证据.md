# `1.仲裁和证据` 归类规则（劳动争议·仲裁阶段）

本目录**只存放**:劳动仲裁申请书、证据目录、证据 1～N、证据(合并)。不放其他任何文件。

---

## 命名规范

| 文件 | 命名格式 | 说明 |
|------|---------|------|
| 仲裁申请书原件 | `仲裁申请书_姓名.docx` | 律师起草的 Word 版 |
| 仲裁申请书盖章版 | `仲裁申请书_姓名.pdf` | 签字/盖章后扫描版 |
| 证据目录原件 | `证据目录_姓名.docx` | 律师起草的 Word 版 |
| 证据目录盖章版 | `证据目录_姓名.pdf` | 签字/盖章后扫描版 |
| 单份证据 | `证据N XXX.pdf` | N 为序号,XXX 为证据名称 |
| 合并证据 | `证据(合并).pdf` | 证据 1～N 合并后的完整版,自动生成 |

---

## 与诉讼阶段目录的对应关系

本目录对应标准诉讼模板的 `1.起诉状和证据`,区别仅在于文书为"仲裁申请书"而非"起诉状"。劳动争议法定仲裁前置,仲裁阶段材料归入本目录;进入诉讼后起诉阶段材料归入 `4.起诉和证据`(复用 `reference/05-dir-1-complaint.md`)。

## 证据自动合并

完成证据制作后自动生成 `证据(合并).pdf`,规则见 `reference/07-evidence-merge.md`。
