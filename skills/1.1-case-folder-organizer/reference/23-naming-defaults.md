# 默认命名规范

当案件文件夹内无命名规范文件时使用。律师案件文件夹内存在自定义规范 docx 时优先使用自定义规范。

---

## 完整默认规范

```
根目录:  编号 案由-委托人姓名
│  .case_snapshot.json    ← 隐藏
│  .case_index.json       ← 隐藏,供其他 skill 读取
│  文件整理操作日志.txt
│  判决书(委托人 一审).pdf
│  判决书(委托人 二审).pdf
│
├── 0.委托发票
│   身份证 姓名.ext / 发票 金额.pdf / 法律服务合同 姓名.pdf
│   授权委托书 姓名.pdf / 所函 姓名.pdf
├── 1.起诉状和证据
│   起诉状_姓名.docx / 起诉状_姓名.pdf
│   证据目录_姓名.docx / 证据目录_姓名.pdf
│   证据1 名称.pdf / 证据N 名称.pdf / 证据(合并).pdf
├── 2.法院通知 一审
│   受理通知.pdf / 缴费通知.pdf / 传票YYYYMMDD HHMM.pdf / 举证通知书.pdf
├── 3.答辩和证据
├── 4.反诉和证据
├── 5.上诉状和证据
├── 6.法院通知 二审
├── 7.答辩二审
├── 8.再审申请和证据
├── 9.法院通知 再审
├── A.财产保全
├── B.执行
│   ├── B1.申请执行/  执行申请书_姓名.docx / 授权委托书_姓名.pdf / 所函_姓名.pdf
│   ├── B2.执行过程/
│   ├── B3.执行异议/
│   ├── B4.执行终本/
│   └── B5.恢复执行/
├── C.参考案例和法规  ← 不改名,不建子目录,直接平铺
├── D.管辖
├── Z.原始证据        ← 不改名、不编辑、不删除(原样保留);但必须只读 OCR 提取并隐藏持久化(.原文件.ocr.txt,leading-dot 隐藏);OCR 结果注册 .case_index.json 供下游读取
└── Z.待归类           ← 临时中转,清空后自动删除
```

---

## 使用注意

- 所有文件名中的括号必须是**半角** `()`,全角 `()` 在整理时自动修复
- 姓名用于识别委托人,从 `0.委托发票/法律服务合同_姓名.pdf` 提取
- 案由命名从起诉状/判决书中提取(如"买卖合同纠纷"、"民间借贷纠纷"、"股权转让纠纷")
