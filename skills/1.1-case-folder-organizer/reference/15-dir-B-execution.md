# `B.执行` 归类规则

---

## 触发条件

识别到任何执行类文件,即建立。

---

## 三级目录

| 目录 | 用途 |
|------|------|
| `B1.申请执行/` | 执行申请阶段 |
| `B2.执行过程/` | **兜底目录**,无法判断子阶段的归此处 |
| `B3.执行异议/` | 执行异议、复议 |
| `B4.执行终本/` | 终本裁定、执行款到账凭证 |
| `B5.恢复执行/` | 多次恢复统一归此 |

---

## B1.申请执行 内容清单

| 文件 | 命名格式 |
|------|---------|
| 执行申请书 | `执行申请书_姓名.docx/.pdf` |
| 授权委托书 | `授权委托书_姓名.pdf`(执行阶段单独出具) |
| 所函 | `所函_姓名.pdf`(执行阶段单独出具) |
| 判决书/裁定书(执行依据) | `判决书_姓名.pdf`(允许与根目录重复) |
| 执行费发票 | `执行费发票.pdf` |

---

## 关键规则

- 执行款到账凭证归入 `B4.执行终本/`
- 无法判断子阶段的文件归入 `B2.执行过程/` 兜底,记录日志
- 被执行方文件暂定归入 `B2.执行过程/`,快照 `pending_issues` 标注"被执行方文件归类规则待细化"
