# 判决书/裁定书识别树

---

## Step 1:提取案号

**位置**:第 3 或第 4 行,靠右对齐的较短行

```
├── 识别成功 → Step 2 按案号类型代码判断
└── 识别失败 → 退回第 1 页标题关键词识别
```

---

## Step 2:按案号类型代码归类

| 类型代码 | 归入 |
|---------|------|
| 民初 | 一审文书 → Step 3 |
| 民终 | 二审文书 → Step 3 |
| 民再 | 再审文书 → Step 3 |
| 民保 / 保全 | `A.财产保全/` |
| 执 | `B.执行/` 对应子目录 |
| 无法匹配 | `Z.待归类/` |

---

## Step 3:判断是否本案文件

1. 从 `0.委托发票/法律服务合同_姓名.pdf` 文件名提取委托人姓名
2. 与文书第 1/2 段当事人姓名比对

```
├── 匹配 → 命名 判决书(姓名 一审).pdf,放根目录
└── 不匹配 → 归入 C.参考案例和法规/,不改名
```

---

## 一审/二审/再审判决书的文件名规范

| 审级 | 命名 |
|------|------|
| 一审 | `判决书(姓名 一审).pdf` |
| 二审 | `判决书(姓名 二审).pdf` |
| 再审 | `判决书(姓名 再审).pdf` |

括号使用**半角**,与文件名全角→半角规则一致。
